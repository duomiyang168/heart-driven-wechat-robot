# 心力驱动微信机器人

一个基于微信桌面版和阿里云百炼 AI 的智能问答机器人，可以在指定群聊中自动回复以"#举手"开头的问题。

## 功能特点

- **智能监听**：监听指定微信群聊消息，识别"#举手"触发关键词
- **AI 智能回复**：调用阿里云百炼 AI 服务生成智能回复
- **消息引用回复**：使用微信引用消息功能，自动引用原问题进行回复
- **问题队列机制**：多个问题按顺序处理，避免并发崩溃
- **性能优化**：使用工作线程异步处理，不阻塞消息监听
- **双重去重**：消息级 + 问题级去重，防止重复处理同一问题

## 环境要求

- Python 3.7+
- Windows 系统（微信桌面版）
- 微信桌面版 4.0.5
- wxauto4 开源版

## 安装步骤

### 1. 克隆项目

```bash
git clone https://github.com/duomiyang168/heart-driven-wechat-robot.git
cd heart-driven-wechat-robot
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 配置环境变量

复制 `.env.example` 文件并重命名为 `.env`：

```bash
cp .env.example .env
```

编辑 `.env` 文件，填入你的阿里云百炼 API Key：

```
DASHSCOPE_API_KEY=your_dashscope_api_key_here
```

### 4. 配置群聊名称

编辑 `newmain.py` 文件，修改目标群聊名称：

```python
TARGET_GROUP_NAME = "你的群聊名称"  # 修改为实际的群聊名称
```

## 使用方法

### 1. 启动微信桌面版

确保微信桌面版已登录并保持运行状态。

### 2. 运行机器人

```bash
python newmain.py
```

### 3. 在群聊中使用

在配置的群聊中发送消息：

```
#举手 如何学习 Python？
```

机器人会自动调用阿里云百炼 AI 服务生成回复，并引用你的提问消息。

## 核心功能说明

### 1. 消息引用回复

机器人使用 `msg.quote()` 方法回复消息，会自动引用原始提问，让对话更清晰：

```
用户：#举手 如何学习 Python？
机器人：(引用上面的消息) 学习 Python 可以从以下几个方面入手...
```

### 2. 问题队列机制

当短时间内出现多个带有 `#举手` 标签的问题时，机器人会：

1. 将所有问题加入队列
2. 按照收到的顺序依次处理
3. 避免并发处理导致的崩溃
4. 实时显示队列状态

示例输出：
```
[新问题入队] 张三 提问：如何学习 Python？
[队列状态] 当前队列中有 3 个问题待处理
[开始处理] 第1个问题，提问者：张三
[处理完成] 问题已回复，耗时：2.34秒
```

### 3. 性能优化

- **异步处理**：使用专门的工作线程处理问题，不阻塞消息监听
- **并发安全**：使用线程安全的队列（`queue.Queue`）
- **快速响应**：消息监听立即返回，后台处理问题
- **错误隔离**：单个问题处理失败不影响其他问题

## 技术亮点

### 基于官方 API 的优化实现

1. **使用 `msg.hash` 属性进行消息去重**
   - 比自定义签名更可靠（切换UI后不变）
   - 自动缓存管理，防止内存溢出

2. **使用 `chat.chat_type` 判断聊天类型**
   - 直接使用官方属性，更准确
   - 代码更简洁，性能更好

3. **使用 `WxResponse` 返回值判断操作结果**
   - 精确判断消息发送是否成功
   - 详细的错误信息便于调试

4. **智能降级策略**
   - 优先使用 `msg.quote()` 引用回复
   - 失败时自动降级为普通消息
   - 确保消息一定能发送成功

## 获取阿里云百炼 API Key

1. 访问 [阿里云百炼控制台](https://dashscope.console.aliyun.com/apiKey)
2. 登录阿里云账号
3. 创建或获取 API Key
4. 将 API Key 填入 `.env` 文件

## 配置说明

在 `newmain.py` 中可以修改以下配置：

- `TARGET_GROUP_NAME`: 目标群聊名称
- `TRIGGER_PREFIX`: 触发关键词（默认为"#举手"）
- `APP_ID`: 阿里云百炼应用 ID
- `REPLY_TEMPLATE`: 回复消息模板
- `MAX_QUESTIONS_CACHE_SIZE`: 问题去重缓存大小

## 注意事项

- 请确保微信桌面版版本为 4.0.5
- 请勿在 `.env` 文件中泄露 API Key
- 建议在测试群聊中先行测试
- 机器人需要微信保持登录状态

## 常见问题

### Q: 机器人无法启动？
A: 请检查微信桌面版是否已登录，版本是否为 4.0.5。

### Q: 机器人不回复消息？
A: 请检查群聊名称是否配置正确，API Key 是否有效。

### Q: 如何修改触发关键词？
A: 编辑 `newmain.py` 中的 `TRIGGER_PREFIX` 变量。
